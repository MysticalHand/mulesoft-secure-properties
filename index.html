Mule Secure Properties

Encrypt and decrypt values for Mule's <secure-properties:config>, the same way the runtime does (ALGORITHM/MODE/PKCS5Padding, useRandomIVs=false). Everything runs locally in your browser and nothing is sent anywhere.

Key and algorithm

When <secure-properties:config> sets neither algorithm nor mode, Mule uses AES and CBC. The key is used as it is, with no derivation, so its length has to match the algorithm: AES takes 16, 24 or 32 characters, Blowfish 1 to 56, DES 8, DESede 24. With any other length Mule itself fails with The key is invalid, please make sure it's of a supported size.

Decrypt

Encryption is deterministic: the same value with the same key, algorithm and mode always produces the same ![...]. That gives you two ways to check a key: decrypt a value from the file, or encrypt a value you already know and compare the result with the file.
